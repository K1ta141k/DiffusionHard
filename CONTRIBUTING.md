# Contributing

Set up the project and run the focused checks from the README.

For numerical changes, include a bit-accurate reference, boundary tests, and a
real-checkpoint comparison where applicable.

For hardware results, state whether the evidence is an analytical estimate,
Yosys technology map, vendor implementation, or physical measurement. Vendor
claims must include the exact part, tool version, constraints, timing, and
resource report.

Do not commit model weights, build trees, user data, or assumed clocks reported
as achieved frequencies.

Contributions are licensed under Apache-2.0.
